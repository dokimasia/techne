# Roadmap

What we are building, in what order, and what has to be true first.
Milestone numbers are permanent. The order is the order of this table,
and it changes.

| Order | Milestone | Status | Depends on | Ships in |
|---|---|---|---|---|
| 1 | [0000](0000-contracts-and-module-rules.md) Contracts and module rules | Done | none | unscheduled |
| 2 | [0001](0001-every-language-outlines-a-file.md) Every language outlines a file over MCP | Done | 0000 | unscheduled |
| 3 | [0002](0002-strongest-tier-for-every-language.md) Every language answers at the strongest tier it can reach | Planned | 0001 | unscheduled |
| 4 | [0003](0003-a-change-is-all-or-nothing.md) A change is all or nothing | Planned | 0002 | unscheduled |
| 5 | [0004](0004-answers-survive-a-changing-workspace.md) Answers survive a changing workspace | Planned | 0003 | unscheduled |

Contracts, then reading, then changing, then speed. Every language moves
together at each step: no milestone raises one language and leaves the
rest behind.
